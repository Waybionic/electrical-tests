# Historical import notes

This repository was assembled on October 8, 2026 from earlier WayBionic test
repositories. The source histories were rewritten only to place their files
under the final `tests/...` directories. Original commit authors, messages,
author dates, and committer dates were retained.

Before publication, hard-coded demo Wi-Fi values in the Servo Mk2 and stepper
histories were replaced throughout the imported history with
`CHANGE_ME_SSID` and `CHANGE_ME_PASSWORD`.

The imported histories cover:

- L298N stepper experiments: August 12–19, 2025
- Servo Mk2 controller: September 7, 2025
- StepperMotor branches and variants: September 6, 2025–February 7, 2026
- Joystick-driven steppers: January 17–24, 2026

The `CAN-bus-test` and `Mark4` source repositories contained no commits when
this archive was assembled, so their directories contain explanatory
placeholders rather than invented historical code.
